# Foundly

A warm, editorial community Lost & Found platform built with React, TypeScript, Vite, Tailwind CSS, and Supabase.

## Features
- **Thoughtful design**: Warm ivory, terracotta, sandstone, editorial typography, and Lucide icons.
- **Home & Browse**: Full-text searching, category and location filters, and newest-first chronological sorting.
- **Photo Uploads**: Direct image uploads to Supabase Storage with local preview.
- **Privacy & Safety**: Contact emails are securely handled; strict RLS prevents anonymous modifications.
